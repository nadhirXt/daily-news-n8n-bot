# Script Reel / TikTok / YouTube Shorts (30 Secondes)

Format vidéo vertical (9:16) dynamique, idéal pour générer un maximum de commentaires et de trafic vers le repo GitHub.

---

## 🎵 Recommandations Musicales & Montage
- **Musique** : Piste instrumentale Lo-Fi rythmée ou Synthwave entraînante (volume à 20% derrière la voix-off).
- **Sous-titres** : Dynamiques, mot par mot, au centre de l'écran (style CapCut ou Subtitles).
- **Rythme de coupe** : Un changement de plan toutes les 2 à 3 secondes maximum pour maintenir la rétention.
